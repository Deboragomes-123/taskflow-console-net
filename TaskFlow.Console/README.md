# TaskFlow - Gerenciador de Tarefas via Console

Aplicação em C# (.NET) desenvolvida para o gerenciamento de tarefas em memória, construída com foco em qualidade de código, testes unitários (xUnit) e boas práticas de versionamento (Conventional Commits).

## Como Compilar e Rodar

1. Certifica-te de ter o .NET SDK instalado.
2. Abre o terminal na pasta raiz do projeto.
3. Para executar a aplicação de consola:
   ```bash
   dotnet run --project TaskFlow.Console/TaskFlow.Console.csproj
